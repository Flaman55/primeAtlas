## What PrimeAtlas is

A desktop application (Windows, tkinter) for generating, storing, browsing and researching prime
numbers and their k-tuple constellations floor by floor (floor N = [10^N, 10^(N+1))). It drives sieve
and constellation engines that run under WSL, keeps their output as compact PGS2 window files in one
storage folder, and offers search, research tools (Goldbach, square intervals, polynomials, gaps,
pi(x) approximations), benchmarks, backups and GPU visualizations on top of that data. It is not a
library and not a server: one user, one machine, one storage folder at a time.

## Processes

```
 Windows                                              WSL (Ubuntu)
 prime_atlas_v2.py ── PortalBrowserApp (tkinter) ──wsl.exe──> orchestrator_loop_v2.py ─> orchestrator_v3.py ─> prime_sieve_v5.py (.so)
        │                │                          │       constellation_finder_v2_3.py
        │                │                          │       ktuple_sieve_v2_2.py
        │                │ log tail (.generation_logs/), stop request files, exit code
        │                └── renderer.py (moderngl/GLFW, separate Windows process; HUD JSON on stdout, RESUME on stdin)
        └── startup_dependency_check.py, env_setup_wizard (before the window)

 both sides read and write the same storage folder (data.md); the Windows path reaches WSL as
 CONSTELLATION_PORTAL_DIR (a /mnt/... path)
```

- The GUI never imports an engine: it builds argv (`primeatlas/generation/engine_argv.py`), launches it
  through `wsl.exe` with the storage path and engine knobs as environment variables
  (`wsl_command.py`), and follows the run through its log file ([flows/generation-run.md](flows/generation-run.md)).
- The visualizations run as a native Windows subprocess per sub-tab ([flows/visualization.md](flows/visualization.md)).
- Self-update talks to the GitHub API or `git fetch` on the app's own checkout (`primeatlas/settings/app_update.py`).

## Rules the design keeps

- The Windows GUI never imports WSL engine code; shared constants are mirrored and kept equal by tests
  ([ADR 0001](../adr/0001-wsl-engines-windows-gui.md)).
- Prime data is stored as PGS2 gap/varint windows, sharded 5000 per folder
  ([ADR 0002](../adr/0002-pgs2-window-format.md)).
- Numbered engine versions are frozen; a change is a new version proven equal or better by tests
  ([ADR 0003](../adr/0003-frozen-numbered-versions.md)).
- A value used by several modules lives in one `*_const` module (fixed) or one `*_dynamic` module
  (computed at startup); the engines pass the storage folder explicitly
  ([ADR 0004](../adr/0004-shared-values-and-explicit-portal.md)).
- k-tuple sieve finds ahead of the exhaustive search never enter the shared hit file
  ([ADR 0005](../adr/0005-gap-safe-provisional-hits.md)).
- The version is read from `CHANGELOG.md`: release plus one numbered entry per merge since it
  ([ADR 0006](../adr/0006-version-from-changelog.md)).
- One file = one purpose, at most 1000 lines (`unitTests/test_line_ceiling.py`; frozen versions are the
  listed exceptions).
- One control per UI role (HeightGrip, ScrollPad, GenerationConsole), app-wide.
- Every user-visible string goes through `Translator` (`strings_en.json` / `strings_pl.json`).
